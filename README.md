# CoinScope

A small crypto market app I built with Flutter for the interview task. It shows live prices from the Binance public API, with a coin list, coin details with a chart, market stats and a watchlist.

## What it does

- Coin list with search, filters and sorting
- Coin detail page with a price chart (24H, 7D, 1M, 3M, 1Y)
- Market stats page (market cap, volume, BTC dominance, top gainers and losers)
- Watchlist, saved separately for each user
- Sign up and login using SharedPreferences
- Light and dark mode
- Loading, error and empty screens
